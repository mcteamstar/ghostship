## Why

Captain's generic single-dispatch rule conflicts with orders that need several reviewers. Carrier runs showed both a clarification stall and a duplicate reviewer.

## What Changes

Keep sequential dispatch as the default guidance. Allow multiple authorized tasks in a single check-in when an order calls for them, with paced starts and per-task tracking.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `captain`

## Impact

Common Captain guidance, built-in orders, maintained documentation, and focused verification.
