# proxy-hosting Specification

## Purpose
Allows the transport to be configured with its externally-visible base URLs for both the file server and MCP endpoint, decoupled from the internal listen address, so that URLs generated for external callers resolve correctly when the transport sits behind a reverse proxy.

## Requirements

### Requirement: GA_FILE_PUBLIC_URL environment variable
The transport SHALL read the `GA_FILE_PUBLIC_URL` environment variable to determine the base URL used when generating presigned file-server URLs (upload and download).

#### Scenario: GA_FILE_PUBLIC_URL is set
- **WHEN** `GA_FILE_PUBLIC_URL` is set to `https://academy.example.com/files`
- **THEN** all presigned file URLs generated by `_sign_file_url` and `_sign_upload_url` SHALL use `https://academy.example.com/files` as their base

#### Scenario: GA_FILE_PUBLIC_URL is unset, GA_HOST_URL is set
- **WHEN** `GA_FILE_PUBLIC_URL` is not set and `GA_HOST_URL` is set to `http://myhost:8001`
- **THEN** all presigned file URLs SHALL use `http://myhost:8001` as their base (existing fallback behaviour preserved)

#### Scenario: Both GA_FILE_PUBLIC_URL and GA_HOST_URL unset
- **WHEN** neither `GA_FILE_PUBLIC_URL` nor `GA_HOST_URL` is set
- **THEN** all presigned file URLs SHALL use `http://localhost:{FILE_SERVER_PORT}` as their base, where `FILE_SERVER_PORT` is the MCP listen port plus one

### Requirement: GA_MCP_PUBLIC_URL environment variable
The transport SHALL read the `GA_MCP_PUBLIC_URL` environment variable to determine the external base URL of the MCP endpoint, usable for any self-referencing URLs the transport produces.

#### Scenario: GA_MCP_PUBLIC_URL is set
- **WHEN** `GA_MCP_PUBLIC_URL` is set to `https://academy.example.com/mcp`
- **THEN** any self-referencing MCP URLs the transport produces SHALL use `https://academy.example.com/mcp` as their base

#### Scenario: GA_MCP_PUBLIC_URL is unset
- **WHEN** `GA_MCP_PUBLIC_URL` is not set
- **THEN** any self-referencing MCP URLs SHALL fall back to `http://localhost:{MCP_PORT}` where `MCP_PORT` is the transport's configured listen port

### Requirement: URL resolution precedence
The file-server URL resolution SHALL follow a strict precedence order: `GA_FILE_PUBLIC_URL` takes priority over `GA_HOST_URL`, which takes priority over the localhost default.

#### Scenario: All three values available
- **WHEN** `GA_FILE_PUBLIC_URL=https://proxy.example.com/files`, `GA_HOST_URL=http://fallback:8001`, and the default would be `http://localhost:64058`
- **THEN** presigned file URLs SHALL use `https://proxy.example.com/files`

#### Scenario: Only GA_HOST_URL set
- **WHEN** `GA_FILE_PUBLIC_URL` is unset and `GA_HOST_URL=http://fallback:8001`
- **THEN** presigned file URLs SHALL use `http://fallback:8001`

### Requirement: Documentation of proxy configuration
The documentation SHALL describe both new environment variables, their fallback behaviour, and the expected URL topology when deploying behind a reverse proxy such as Caddy.

#### Scenario: Configuration reference updated
- **WHEN** a user reads `docs/configuration.md`
- **THEN** they SHALL find entries for `GA_FILE_PUBLIC_URL` and `GA_MCP_PUBLIC_URL` with descriptions, defaults, and example values

#### Scenario: Architecture guide updated
- **WHEN** a user reads `docs/architecture.md`
- **THEN** they SHALL find a section explaining the proxy URL topology: which URLs are internal (listen addresses) vs external (proxy-facing), and how the env vars map between them
